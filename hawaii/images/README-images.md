# images 폴더 안내

`planittour-hawaii-v5.html` 과 같은 위치에 이 `images` 폴더가 있어야 합니다.

| 폴더 | 용도 |
|---|---|
| `hotels/` | 호텔 사진 (호텔당 1~3장) |
| `options/` | 유료 옵션 사진 (옵션당 1장) |
| (이 폴더) | `logo.png` 회사 로고 |

## logo.png

- 배경 투명 **PNG** 권장, 가로 400px 내외
- 없으면 `PLANITTOUR` 글자로 자동 대체됩니다

## 우선순위

**자주 쓰는 호텔 10~20개**만 먼저 넣으셔도 됩니다. 없는 이미지는 회색 점선으로 표시되고 그 안에 필요한 파일 경로가 적혀 있습니다.
