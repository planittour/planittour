## 표시 방식

| 화면 | 배치 |
|---|---|
| 모바일 | 한 장씩 · 좌우로 밀어서 넘김 (아래 점으로 위치 표시) |
| 태블릿 이상 | 2~3열로 나란히 |
| 인쇄 | 3열로 나란히 |

**1장만 넣어도 됩니다.** 2번째·3번째 파일이 없으면 자동으로 빠지고, 있는 것만 표시됩니다.
전부 없으면 회색 점선 자리로 표시됩니다.
